# KVÉ — тестовая доработка

Доработка существующего приложения, основанная на `8ac33b15fd7ed8e067ae236c0118b84e9e028beb`. Основная версия не должна заменяться до проверки владельцем.

## Запуск

Статическое приложение без сборки и серверных зависимостей. Из каталога проекта: `python3 -m http.server 4173`, затем открыть `http://localhost:4173`. Для разработки тестов нужен Node.js 20.19+ / 22.12+ / 24+; установить зависимости командой `npm install`, запустить `npm test`.

В рабочей поставке нужны `index.html`, `app.js`, `storage.js`, `recommendations.js`, `enhancements.css` и исходная иконка `apple-touch-icon .png`. Не публикуйте только HTML без остальных файлов.

## Что изменилось

- Идеи: фото скрыто в списках и поиске, доступно при открытии и редактировании; фильтры «Все / Без фото / С фото»; перенос фото, текста и тегов в образ. Если фото нет, открывается форма образа с перенесёнными данными; идея удаляется лишь после успешного сохранения нового образа.
- Папки: отдельная страница, переименование с обновлением ссылок, удаление без удаления образов, загружаемая обложка или фото первого образа.
- Единый поиск из главной строки: образы, их теги/заметки/папки, идеи и их теги/текст, папки. Группы результатов и фильтры по типам.
- Избранное: сердце на карточке и в деталях, отдельный фильтр, сохранение после перезагрузки.
- «Что надеть?»: повод, настроение, сезон, погода. Только сохранённые образы; совпадения по параметрам, тегам, заметкам и папкам. Явно несовместимые параметры исключаются, частичные совпадения подписаны. Параметры образа необязательны.
- List: единая кнопка «Добавить вещь» и полная карточка вещи с названием, ссылкой, ценой/валютой и сжимаемым фото; редактирование, выполнение/возврат, удаление и фильтры. Поля кроме названия необязательны. Старые пункты совместимы. Нижнее меню: Образы · Папки · + · Идеи · List.
- Сохранение: откат при ошибке, блокировка конфликтующей записи из другой вкладки, защита повреждённых данных и более новой схемы от перезаписи, резервная копия и подтверждаемое восстановление.
- Исходные цвета, логотип, размеры основного меню, сетка 3 в ряд и сжатие фото сохранены. Добавлены отступы для безопасной области экрана iPhone. Путь к иконке исправлен под её реальное имя.

## Структура

- `index.html`: существующая разметка и базовые стили, новые экраны.
- `app.js`: существующие обработчики образов/идей и новые функции интерфейса.
- `enhancements.css`: стили новых компонентов поверх исходных.
- `storage.js`: граница локального хранилища, чтение/проверка/сохранение/экспорт.
- `recommendations.js`: независимый, заменяемый алгоритм подбора.
- `tests/app.test.cjs`: 25 регрессионных и интеграционных проверок через DOM-модель.
- `ANALYSIS.md`: исходное состояние, план и следующий этап облачного хранения.

## Данные

Ключ `kve-v01` сохранён. Старые массивы `looks`, `ideas`, `folders`, фотографии и поле `folder` продолжают читаться. Новые поля добавляются без удаления неизвестных полей. При запуске ничего автоматически не записывается. Удаление/преобразование/переименование показывают успех только после записи. Резервная копия содержит фотографии, её следует хранить как личный файл.

Данные тестовой версии на отдельном адресе не появляются автоматически из основного приложения: localStorage привязан к адресу и браузеру. У тестовой версии нет доступа к данным основного сайта. Для проверки с копией своих данных можно восстановить JSON через меню •••. Сама основная версия пока не содержит новой кнопки экспорта.

Аккаунты, облако и синхронизация пока НЕ подключены. На общем браузерном профиле локальные данные общие для всех, кто им пользуется. Это не изоляция аккаунтов. Приложение не отправляет сохранённые фотографии или данные на сервер.

## Проверено

Все 25 автоматических проверок прошли: основные операции с образами и идеями, несколько папок, теги/заметки, преобразование, поиск, папки/обложки, избранное, List, подбор, старый формат, экспортируемые данные/импорт, ошибки записи, конфликт вкладок и отмена загрузки фото.

В браузере отдельно проверены: загрузка реальной PNG с преобразованием в превью, сохранение образа с двумя папками/тегом/заметкой, открытие деталей, избранное, добавление/редактирование List и подбор по летнему тегу. Проверен вид при ширине 390 px.

Осталось проверить владельцу: реальный iPhone/Safari, добавление на экран «Домой», клавиатура и safe-area внутри Telegram Web App. Эмуляция ширины не заменяет проверку на устройстве. Автоматические тесты не моделируют реальный Canvas, поэтому загрузка фотографии проверялась также в браузере.

Интерфейс использует единую гарнитуру Arial для кириллицы и латиницы. Иконки нижнего меню и центральный плюс выполнены в SVG с общей толщиной линии, без зависимости от символов системного шрифта.
